⚔️ Security demo: two Admin API paths

🔓 Insecure

Routes like /admin/transfer accept {from,to,amount} verbatim — no ownership check. The Genie can be tricked into naming any from. This is the heist.

🔒 Secure

/admin/secure/transfer re-derives the source from the pinned x-participant-sub header, allow-lists the destination, and enforces a per-transfer limit. The LLM can never name a source.

This console uses the authenticated Customer-API admin surface (Cognito group, no static key). The insecure/secure contrast above is the separate x-api-key Admin API consumed by the Workato Genies.
