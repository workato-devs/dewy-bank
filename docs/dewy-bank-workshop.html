The lethal trifecta

An agent becomes exploitable when it has
  1. Access to your private data
  2. Exposure to untrusted content
  3. The ability to externally communicate in a way that could be used to steal your data

— Simon Willison, "The lethal trifecta for AI agents", June 2025

Participant setup

  • Sign up in the bank app with your email.
  • Configure: wk auth login -p <profile>, then put WORKATO_API_TOKEN and DEWY_SUPPORT_API_KEY (the support code) in .env.
  • Deploy: python3 scripts/deploy_workato.py --profile <profile> --bank-url <bank URL>.
  • When it pauses, connect both connections in Workato: Customer API with your bank email and password; Support API just needs Connect.
  • Set up chat: paste the JSON it prints into the bank app at Settings → Chat. Then pick a station and a server in the chat.
From the dewy-bank README "Deploy your Workato workspace". The script stamps the connectors, pushes everything in order, starts the recipes and prints the chat blob (also saved to .agents/tasks/chat-config.json). Run it from the repo root.
